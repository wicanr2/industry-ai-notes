    Memory Is Not Ground Truth：撤回記憶導航權，不等於物件不存在¶

    問題：機器人回到記憶位置卻找不到物件，應刪記憶、繼續重試，還是只撤回這筆記憶的導航權？ 方法：保留歷史影像，把負觀測按幾何來源分組，再以可逆狀態機決定記憶是否能直接產生導航目標。 判讀：本文最有價值的是把「物件是否存在」與「目前是否值得依它行動」拆開；實驗支持決策路徑改變，尚未證明搜尋更快、全自主成功率更高或休眠記憶有效復權。

    1. 缺口不是記憶不會更新，而是更新了哪一種東西¶

    §I–III 的問題是：同一個「沒看到」可能源自物件移走，也可能源自視角、遮蔽、目標身分描述或 VLM 的固定盲點。反覆回到近似視角，未必產生更多有區辨力的資訊。

    既有動態記憶／觀測模型已會處理不確定性；作者沒有宣稱自己首次提出更新記憶。更窄的缺口是：若物件仍在與物件移除都產生完全一樣的 verifier 輸出，只靠這串輸出降低存在機率，不能解決可辨識性問題。本文因此改決策標的：不求從漏檢證明消失，先決定要不要繼續把移動與推論預算花在這個導航假說上。

    這也不是安全授權：這裡的 authority 只指能否成為正常直接導航目標，不是急停、碰撞檢查或人類批准。

    2. 任務定義、輸入輸出與必要狀態¶

    §III 把記憶寫成：

    \[ m_i=(q_i,z_i,x_i,t_i). \]

    其中 \(i\) 是記憶編號，\(q_i\) 是目標文字描述，\(z_i\) 是歷史視覺觀測，\(x_i\) 是當時的機器人觀察位姿，\(t_i\) 是觀測時間。它不是物件的三維座標估計。

    目前觀測經固定驗收規則後，產生二元結果 \(Y_t\in\{0,1\}\)，即時間 \(t\) 的未通過／通過。物理真值 \(H_t\in\{\mathrm{present},\mathrm{absent}\}\) 則代表記憶位置的物件是否仍在；兩者不能混同。作者以

    \[ p_D(c_t,q)=P(Y_t=1\mid H_t=\mathrm{present},c_t,q) \]

    表示觀測條件 \(c_t\)（視角、可見度、遮蔽、尺度）與語言查詢 \(q\) 都會影響偵測率。\(P\) 是條件機率，\(p_D\) 只是問題記號，論文沒有假設它已校準或學得此函數。所以 \(Y_t=0\) 不推出 \(H_t=\mathrm{absent}\)。

    系統另外保存每筆記憶的 actionability 狀態及負證據分組歷史。輸入是文字目標、四路固定相機、位姿及持久記憶；輸出是當前目標確認，或經 /goal_pose 發布的記憶回訪／語意 frontier 目標。這是高階搜尋決策，不是 VLA 直接輸出馬達控制。

    3. 方法：歷史影像只給回訪假說，新影像才准完成任務¶

    3.1 記憶與搜尋流程（§IV-A–B）¶

    1. Spot 先檢查四路當前相機。有嚴格正確認才更新記憶並結束任務。
    2. 若未找到，以 CLIP embedding 加 FAISS 檢索歷史關鍵幀；每幀保留四路影像、位姿、時間與任務脈絡。相似度高不等於物件已被驗證。
    3. VLM 重新檢查候選的歷史影像。通過只支持把當時觀察位姿當成回訪假說，不能宣稱當前已找到。
    4. 僅正常可信的記憶可直接產生回訪目標；沒有這種記憶時，對幾何可行 frontier 做 VLM 語意排序。實驗的排序完全採語意分數，幾何負責先篩可行候選，不是語意／距離折衷排序。
    5. 到達目標或移動途中取得新正觀測，才確認任務完成；記憶回訪失敗則記錄相應負證據。

    全系統共用凍結的 Qwen3-VL-8B-Instruct。接受條件包括目標可見、模型回報 confidence 至少 0.85、ambiguity 至多 0.15、有直接視覺證據且身分吻合。這兩個數字是驗收契約的門檻，不是已校準的成功／錯誤機率。

    3.2 可逆狀態機與幾何去重（§IV-D、Table I）¶

    • VERIFIED_ACTIVE：可走正常直接導航路徑。
    • 第一組負證據使其變成 SUSPECT：此時已撤回正常直接導航權，不是等第二次才撤權。
    • 第二組幾何不同的負證據使其變成 DORMANT_UNTRUSTED：繼續記錄缺乏支持；它和 SUSPECT 都不能作正常可信直接導航目標，差別主要在累積歷史，不是不同的物件存在機率。
    • 歷史影像不刪除；後續嚴格正確認可恢復 VERIFIED_ACTIVE。這是規則允許的路徑，是否在實驗確實從 dormant 復權，須另看證據。

    幾何分組門檻是人工設計：平移差至多 0.15 m 且朝向差至多 7.5° 視為同一本地來源；相對前一組至少差 0.50 m 或20° 才開新組；中間區間不新增組。重複局部漏檢不重複計數。

    本筆記判讀：幾何新穎只是去重代理，不保證統計獨立，更不保證新視角真的看見目標。且第一組就撤權，E4 的決策結果不能單獨證明第二階狀態或分組門檻有額外效益；需要等記憶保留條件的消融。

    3.3 資料、訓練與非同步控制邊界（§IV-C、§V-A）¶

    本文沒有新模型訓練目標或梯度更新；核心改動是凍結 VLM 周邊的記憶／決策規則。資料是單一室內工作區的真機觀測、重訪及人工物件移除；不是大規模學習資料集。

    移動中先用 CPU CLIP 篩影像，再把候選送同一常駐 VLM worker；場景確認、歷史確認、frontier 排序與移動感知共享模型。正確認會結束目前搜尋目標並提升新觀測為已驗證記憶。這支持單模型資源共享的可行性，但未提供排程尾延遲、能耗或獨立停止鏈的量測；終止高階目標也不等於證明實體即刻停止。

    4. 實驗分開看：感知辨識、更新取捨、決策改變¶

    E1：漏檢不是同一種強度的負證據（§V-B、Table II）¶

    四個目標各 16 個實體視點、四路相機，共 256 張影像；人類標註目標在影像中可見的有 63 張，另外 193 張不可見。原查詢得到 42 個真陽性、21 個假陰性、0 個假陽性與 193 個真陰性，可見樣本 recall 為 66.7%。藍椅、紅凳漏檢率分別 66.7%、62.5%，橘錐 16 張可見影像全通過。

    固定同一批影像改查詢：單純改寫不改變可見樣本決定，放寬為類別描述則救回 21 次漏檢中的 11 次，但也把不同椅子接受為目標。作者結果支持查詢與目標依賴；不支持用放寬身分條件免費修復感知。 這是 image-level visibility 分母，不能轉寫成「物件在場就一定可見」的偵測率。

    E2：多次呼叫不等於多份獨立證據（§V-C）¶

    挑選 8 個可見錨點，每點離開再返回 6 次，48 張前相機觀測仍可見。40 組相鄰轉移中有 36 組維持同一 verifier 結果，即 90.0%。作者明說錨點是刻意挑選，這只是描述性對照，不能拆出真正時間依賴與固定視角／目標盲點，更不能當隨機母體的顯著性結論。

    E3：同一串漏檢，可能來自不同物理世界（§V-D、Table III）¶

    實體移走物件後，回到對應 8 個區域各 6 次；48 張都被拒。但藍椅三個錨點在「人可看見物件」與「物件移除」兩條件都產生六連漏檢。幾何審核在揭露輸出前完成；C1 朝向超容差仍以結果盲化決定保留，排除後不改定性結論。

    作者的對照不是原論文系統端到端重現：

    • 按漏檢次數剔除：門檻一至三次只保住 3/8 有效記憶，六次則保住 5/8；兩者皆拒絕 8/8 移除物件記憶。
    • 幾何分組回放：保住 30/48 有效 trajectories，拒絕 48/48 移除 trajectories；18 次誤降權均是藍椅。這些分母不是前一項的 8 個 anchors，不能混成同一組獨立試驗。
    • 加保持身分的查詢改寫，或給歷史參考影像，未改善該回放對照。另做同物件影像比對時，12 個在場及 12 個移除比較全未接受。
    • Table III 的 LCOM-style、PBD-AG-style 是 common-interface adaptations。它們展示更新規則與先驗的取捨，不足以宣稱擊敗原論文完整導航系統。主文未完整展開這些 adaptation 的所有實作，這次也未審碼。

    本筆記判讀：同初始條件／參數、同一串 verifier 輸出，只用這串輸出的 updater 無法區分這兩個測試世界；這不是「物件消失永遠不可推知」的定理。換感測器、可見性估計或主動視角可能提供目前缺失的資訊。

    E4：三個高階目標選擇，不是三次全自主導航成功（§V-E、Tables IV–V）¶

    先移除紅凳，失敗回訪產生 SUSPECT，凍結這份共同歷史，再從三個 matched starts 比較：episode-local baseline 忘掉前次失敗，三次都選記憶目標；新規則三次都選 frontier。三個起點共用同一次建構的失效歷史，不是三個獨立統計試驗。

    關鍵驗收邊界：配對比較在高階目標被選出並發布就停止；長距離實體移動由操作者朝系統目標遙控，以隔離低階導航失敗。故它證明自主高階決策改變，不證明全自主 traversals、總距離、搜尋時間、能耗或端到端成功改善。

    互補的移動感知試驗把紅凳放回，系統處理 17 個途中觀測、發出 9 次 VLM verification，未載入第二模型，途中正確認提升新記憶並完成任務。這不是從 dormant 記憶復權的獨立成效驗證；§VI 也明確保留此限制。

    5. 第一性原理：最小狀態與有效條件¶

    本筆記推論，非作者新增實驗：

    • 最小必要狀態不只有影像與相似度，還要有來源位姿／時間、曾驗證身分、跨 episode 的負證據來源，以及「現在能否驅動導航」的狀態。否則 agent 每次都可能重啟同一個失敗假說。
    • 資訊限制：若觀測通道對某目標持續失明，增加相同來源的樣本量不會自動補回區辨資訊；把幾何去重叫成「獨立證據」仍會過度推論。
    • 物理與資源限制：回訪要付移動、感測及模型推論成本；撤權可能減少無效執著，也可能離開其實就在附近的有效目標。本文尚未量這筆機會成本。
    • 有效條件：替代 frontier 至少要有取得新證據的機會，且恢復路徑可達。若 CPU 篩選持續漏掉該物件、所有新視角仍落同一盲點，或永久排除回訪使復權機會耗盡，保存資料本身不保證能恢復。
    • 機制與效益分帳：本方法能改變誰可驅動決策，但沒有解決目標身分真偽，也未保證新目標比舊目標划算。可逆狀態機是一種資源治理規則，不是已學得的最優搜尋策略。

    6. 可複用模型與後續驗證¶

    可複用的不是三個狀態名稱，而是四層分帳：歷史曾觀察到 → 當前通道能支持 → 是否准它繼續驅動行動 → 替代行動是否改善整段任務。撤回行動權不必同時刪除歷史事實，也不能冒充推知現況。

    與 Memory Clock對讀，是「記憶保留／壓縮了什麼」之外再問「它目前有什麼決策權」；與 LEASH只作 authority 接口對照，物件記憶的導航權不是人類授權，未驗證整合。

    1. 固定同一持久失敗歷史，對照「一次撤權」「兩階分組」「時間退避」及「可見性分組」；同時量有效目標被錯放棄、總搜尋成本與完整成功，才能判定分組／第三狀態是否有額外價值。
    2. 明確從 DORMANT_UNTRUSTED 出發，在未知回復時刻及不同目標上，測復權率、等待時間與篩選漏失；不能只展示新記憶 promotion。
    3. 以全自主低階導航及固定單模型服務預算做多環境、多次歷史的評估；分報高階選擇、到達、正確認、物理停止與完整任務，而不是只用避免舊目標的比率。
