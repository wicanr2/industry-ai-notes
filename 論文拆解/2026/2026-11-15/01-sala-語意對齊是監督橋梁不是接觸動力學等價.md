# SALA：語意對齊是監督橋梁，不是接觸動力學等價

人類影片可以教同一個動作專家，但「影片看來相似」不保證教到可控制的行為。
SALA 用語言建立跨形體的軟鄰居關係，以有真實動作監督的機器人 latent 為錨，再讓人類影片加入策略訓練。
關鍵證據是對齊消融與下游結果；不能把離線動作誤差下降、語意檢索改善和真機完整成功混成同一條 scaling law。

## 1. 問題不只是缺資料，而是監督目標能否跨形體轉用

只用前後影格重建來學 latent action，模型可以把背景、視角或非控制因素裝進瓶頸。兩段都叫「抓杯子」的影片，若一段是人手、一段是機械手，重建損失本身沒有要求其 latent 相近；反之，同背景下不同動作也可能被放在一起。

本文不是從人手關節直接 retarget 成機器人命令，也不是部署時先生成影片再反推動作。它要造的是**訓練監督橋梁**：讓人類影片產生能被機器人 action expert 使用的預測目標。這需要同時保住控制資訊與跨形體關係，不能只靠影片量大。

## 2. 方法：先學控制錨點，再對齊關係，最後訓練策略

### 任務與輸入輸出

Tokenizer 的人類資料有影片端點與原子動作文字；機器人資料另有起始狀態與後續 action chunk。兩邊獨立收集，不要求一對一配對。原子動作文字是 tokenizer 訓練用的標註，不等於策略收到的任務指令，也不是所有後續人類影片都必須重新標註。

部署策略輸入當前 RGB、任務語言及機器人關節狀態，輸出關節目標 chunk；未來影格只用於離線教師產標，部署不需要它或教師 tokenizer。

### A. 控制落地：latent 不能只會解釋畫面

共享視覺編碼器讀取間隔為 $k$ 的兩個觀測，產生 latent，再經 SoftVQ 壓縮。$k$ 是影格間隔，不是固定秒數；不同來源依速度使用不同間隔。視覺 decoder 預測未來的凍結 DINOv2 特徵；只有機器人片段另經 action decoder，由量化 latent 與起始狀態重建真實 action chunk，以 Huber loss 訓練。

架構把每段壓成 8 個 tokens，每個 token 是 256 個 code 的機率分布，不是單一硬編碼。真機 tokenizer 讀頭部與兩個手腕視角。本文的「控制錨點」來自機器人動作重建監督，不是文字已理解物理的假設。

### B. 語言關係蒸餾：對齊一整列鄰居，不硬配一個樣本

對人類片段 $i$ 與同批機器人片段 $j$，定義

$$
P_{ij}=\operatorname{softmax}_j(s^\ell_{ij}/\tau_\ell),\quad
Q_{ij}=\operatorname{softmax}_j(\operatorname{sim}(z_i^H,\operatorname{sg}(z_j^R))/\tau_z),\quad
\mathcal L_{\mathrm{align}}=-\mathbb E_i\sum_j P_{ij}\log Q_{ij}.
$$

$s^\ell_{ij}$ 是凍結文字編碼器的語意相似度；$z^H,z^R$ 分別是人類與機器人的量化前 latent，$\operatorname{sim}$ 是逐 token 平均的 cosine similarity；$\tau_\ell,\tau_z$ 為 softmax 溫度，控制鄰居分布尖銳程度。$P$ 是文字教師提供的軟鄰居，$Q$ 是希望 latent 學到的鄰居；交叉熵要求兩列接近，而非聲稱每段都存在完全等價的機器人片段。

$\operatorname{sg}$ 表示 stop-gradient：這條對齊梯度不穿過機器人分支，但**不代表整個機器人 tokenizer 凍結**；共享參數仍由其他重建損失更新。SoftVQ 讓連續關係反映到機率 tokens，作者以 hard VQ 對照展示對齊 loss 難下降，兩者視覺重建卻相近。

總 tokenizer 目標由人／機器人視覺重建平均，加上加權機器人動作重建、語意對齊組成。這不是免費的無標註學習：真機 tokenizer 用 27,406 段、983 小時人類子集及 70,859 條、888 小時機器人資料，這些用於 tokenizer 的資料需要原子動作描述。模擬文字可由任務程式切段生成；本次所讀未見真機標註品質與人力成本的完整量化。

### C. 策略學習：人類資料確實更新控制用的 expert

教師凍結後，替影片輸出軟 tokens $y$。策略以 Qwen3-VL-4B 和獨立的 0.6B action expert 組成；expert 加入可學習 latent queries，預測分布 $\hat y$，並讓 noisy action tokens 注意到 queries。其目標為

$$
\mathcal L_{\mathrm{policy}}=\mathcal L_{\mathrm{FM}}^R+
\lambda_{\mathrm{LA}}\left[D_{\mathrm{KL}}(y^R\|\hat y^R)+D_{\mathrm{KL}}(y^H\|\hat y^H)\right].
$$

上標 $R,H$ 表示機器人與人類資料；$\mathcal L_{\mathrm{FM}}^R$ 是只有機器人 action labels 能提供的 flow-matching 動作損失，$D_{\mathrm{KL}}$ 衡量教師與預測的類別機率差異，$\lambda_{\mathrm{LA}}=0.1$ 是 latent 監督權重。人類分支沒有機器人狀態與 noisy actions，只訓練 latent queries 路徑；不是替人類影片憑空補出關節標籤。

流程為人類影片 latent 預訓練 → 機器人資料 mid-training → 特定任務的人／機器人資料 post-training。推論不生成未來影片，直接由 expert 產生動作。附錄平台輸出 32 步、60 Hz 的 63 維相對關節目標，影像 30 Hz；雖平台有指尖觸覺，策略**沒有使用觸覺**。本文未充分交代 chunk 重規劃／執行交接、尾延遲與急停規格，本筆記不代補控制安全迴圈。

## 3. 實驗到底支持哪一層主張？

### 模擬：跨機器人，不是直接的人到機器人測試

RoboTwin 2.0 共 50 個雙臂任務：目標 Aloha-AgileX 只有 clean 的 2,500 條完整軌跡，非目標 ARX-X5 提供 clean／random 共 27,000 條無動作影片。每任務、每場景設定 100 rollouts，指標為任務平均成功率。

Table 2：SALA clean／random／平均為 80.2／48.6／64.4%；π0.5 為 70.7／46.6／58.7%，RotVLA 為 74.4／28.0／51.2%，OpenWAM 為 86.8／3.9／45.4%。比較還含 X-VLA、FastWAM、LingBot-VA、InternVLA-A1.5、UniVLA、UniT。**SALA 不是 clean 最好**；最大訊號是部分影片重建模型在 random 場景大幅退步。

公平性邊界：WAM／LAM 額外使用相同跨形體影片，不代表初始化、模型大小、訓練成本與語言監督完全一致；VLA 組只用目標資料。主榜是配方比較，不能獨立歸因語意對齊。

### 消融：比主榜更接近對齊的因果問題

Table 5 保持策略訓練方式，移除 alignment 後 clean／random 為 75.5／36.8%；移除 stop-gradient 為 73.5／46.8%，完整配方為 80.2／48.6%。這支持對齊與單向錨定在此設定有用，但未見這組閉迴路結果的多 seed 誤差條。

附錄 Table 6 的 top-1 檢索：真機共享任務 same-task 從重建-only 的 3.8% 升到 34.2%，但雙手動詞同時相同仍只有 17.0%，語言直接檢索參考值為 66.4%。**更好的對齊不等於已經語意無誤。** 檢索的語言相似度又沿用相同描述信號，不能單獨充當接觸物理能力的獨立證據；位移誤差、閉迴路結果是不同補充測量。

### 真機：後訓練成功與預訓練離線誤差要分帳

四任務為齒輪組裝、雙手倒藥丸、插花、湯匙舀米；每方法每任務 20 trials。成功要求整段完成，例如三齒輪均嚙合且放手後保持，倒藥無可見灑出且兩杯放正，舀米還須把湯匙放回架上。

Table 4：SALA 四任務 75／80／55／80%，平均 72.5%；GR00T N1.7 平均 41.25%，同架構移除 latent 的 vanilla VLA 為 27.50%。但 SALA 額外用了人類預訓練及任務人類示範，不能把這個差距全算給 alignment loss。

- **預訓練軸**：0、473、1,103、2,678「等效人類影片訓練曝光小時」，mid-training 固定一個 epoch，任務後訓練固定 30,000 iterations。指標是 held-out 遙操作資料的相關關節 L1 動作誤差；不是各預訓練點都量真機成功。等效曝光不應偷換成獨立新增影片時數。0 小時變體仍保留 latent 訓練，也不等於 vanilla VLA。
- **後訓練軸**：固定 2,678 小時預訓練模型與機器人示範，任務人類示範比例 10／50／100%；作者報平均真機成功由 53.75% 到 72.5%。這條軸比主表更接近「多加人類影片有用」，但仍未給等算力重複訓練／資料多樣性的完整分解。
- 四任務的機器人／人類示範條數依序為 1,466／2,715、474／2,466、793／2,117、491／1,973；不是零機器人示範遷移。作者結論明說預訓練 scaling 每設定只有一次 run，較大尺度及離線改善如何轉成真機成功仍待確認。

未見完整按失敗原因分解、長時間運作、接觸力／碰撞風險、人工救援率或安全約束的評估；插花 55% 顯示仍有失敗，但不能據此編造具體失敗原因。

## 4. 第一性原理：什麼可以刪，什麼不能刪？

**本筆記判讀**：影片重建無法唯一識別控制行為；SALA 額外放入動作監督與語言關係，相當於用兩種約束減少歧義。人類影片的價值不是直接提供機器人馬達命令，而是讓產生命令的網路多學一種有方向的預測目標。

最小必要狀態至少包括當前視覺、機器人構型、任務，以及能區分相似畫面下不同接觸／動作的資訊。兩個影片端點和「抓杯子」可能仍分不清抓握力、摩擦、物體重量、遮蔽接觸與可達性；語意鄰近不等於物理等價。若文字把應分開的行為壓成同一類、機器人錨點覆蓋不足，對齊可能導入錯誤共享。這是待測失效假設，不是本文已觀察到的失敗分類。

與[動作 token × 梯度路由](../2026-11-07/01-gradient-routing-隔離梯度之前先問誰教表徵學動作.md)對讀：共同問題是誰在訓練中教控制表徵，但該文動作 tokens 部署不解碼，本篇 latent queries 參與 action expert 的資訊路徑；不能因都叫輔助目標就當成同一機制。本文的 stop-gradient 是對齊分支錨定，亦不等於該文 expert-to-VLM 梯度路由。這只是方法對照，沒有跨篇整合驗證。

## 5. 三個可執行的後續驗證問題

1. **真的是動作語意嗎？** 固定模型、曝光與算力，比正確描述、同名詞錯動詞、動詞正確但接觸條件錯誤的對齊；同時測檢索、動作誤差與完整任務成功，檢查文字捷徑。
2. **多資料還是多更新？** 固定訓練步數，改獨立影片多樣性；再固定獨立資料，改重複曝光，做多 seed 真機驗證，不能只接離線 L1 曲線。
3. **語意相近卻物理不同時怎麼辦？** 對重量、摩擦、遮蔽與接觸狀態做配對擾動，比是否加入觸覺／力訊號，另報碰撞與人工救援；成功率不能折抵安全失敗。
