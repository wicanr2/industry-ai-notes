## 共同觀察與下一個缺口

## 取得與發布限制

一般 web_extract 後端僅支援搜尋、無法擷取 URL，已改用本機 HTTP 與 Jina reader；官方 PDF 直接下載並用 pdftotext 讀取。一次探索 PMI 的非正式路徑回覆 404，已排除，正式連結由中央社列表重新確認。連結檢查時，中央社與中經院原件皆 HTTP 200；日經原站直接請求回覆 403，因此不宣稱原站可由本機直讀，首頁與核電兩頁正文係經 reader 取得，其餘日經候選僅讀首頁摘要。日經頁面模板／行情可能與抓取時點不一致，不採用行情作本輪時間快照。
